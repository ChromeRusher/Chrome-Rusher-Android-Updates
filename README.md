# Chrome Rusher para Android · Actualizaciones

Canal público reservado para distribuir las futuras actualizaciones de Chrome Rusher para Android.

La adaptación para Android todavía no está implementada. No hay versiones, APK ni AAB publicados.

Este repositorio contendrá únicamente versiones compiladas, notas y metadatos de actualización. El código fuente del juego se mantiene privado.

Windows dispone de su propio canal: [Chrome-Rusher-Updates](https://github.com/ChromeRusher/Chrome-Rusher-Updates).
